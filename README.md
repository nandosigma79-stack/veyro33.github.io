# VEYRO FNaF Website

Komplette deutsche Veyro-Gaming-Website für GitHub Pages.

## Enthalten

- Deutsche Texte und Navigation
- FNaF / Horror-Gaming-Design
- Beide hochgeladenen Veyro-Fotos
- YouTube-Link: https://www.youtube.com/@veyro33
- Responsive Darstellung für PC und Handy
- Hover-Effekte und Scroll-Animationen
- Keine Frameworks nötig

## Lokal testen

`index.html` doppelt anklicken.

## Eigene Links eintragen

In `index.html` kannst du die Platzhalter für TikTok, Instagram, Discord, Twitch und E-Mail durch deine echten Links ersetzen.
